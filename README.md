# Design Hub

Общий вход для агентов, которые проектируют, собирают или проверяют дизайн. Начни с [основного скилла](skills/design-hub/SKILL.md). При работе в этой папке его подсказывает [AGENTS.md](AGENTS.md).

## Что внутри

- [Cook](vendor/cook/SKILL.md) содержит оригинальный цикл Леона Лина, антислоп-правила, шаблоны брифа и журнала, инструкции для независимых ревью и сценарий сравнения рендеров. 12 файлов в `vendor/cook` совпадают с исходными Git-объектами закреплённого коммита. [Исходный коммит](https://github.com/Leonxlnx/cook/tree/b23cac6fd9439dfddcab61b14808e7bf72549b46) · [Лицензия MIT](vendor/cook/LICENSE).
- [Концепты через генератор изображений](skills/design-hub/references/image-concepts.md) позволяют выбрать визуальное направление по картинкам перед реализацией.
- [Антислоп-правила](skills/design-hub/references/anti-slop.md) собирают шаблонные приёмы, их уместные замены и порядок проверки рендера.
- [Независимое дизайн-ревью](skills/design-hub/references/design-review.md) задаёт, когда вызывать подагента-судью, что ему передавать и как проверять исправления.
- [Impeccable](skills/design-hub/references/impeccable.md) содержит оригинальный скилл, команды для дизайна и ревью, локальное браузерное сравнение и детектор. Здесь же есть ссылки на полный открытый комплект, документацию и галерею.
- [Проверка дизайна по формату](skills/design-hub/references/quality.md) покрывает интерфейсы, сайты, презентации, документы и графику.
- [Референсы и инструменты](skills/design-hub/references/tools.md) содержит источники, инструменты захвата и команду для оригинального скрипта Cook на Windows.

## Подключение

Локальные сессии Codex берут короткое правило из `~/.codex/AGENTS.md`, Claude Code — из `~/.claude/CLAUDE.md`. В обоих профилях точка входа `design-hub` ведёт к одному основному файлу. Начни новую сессию после подключения. Для явного вызова в Codex доступен `$design-hub`, в Claude Code — `/design-hub`. [Инструкции Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md) · [Инструкции Claude Code](https://code.claude.com/docs/en/memory).

Inspo MCP добавлен в пользовательские конфигурации обоих клиентов. Для другого клиента со Streamable HTTP укажи `https://inspomcp.dev/api/mcp` или открой [веб-каталог Inspo](https://inspomcp.dev/).

Для другого агента добавь в его постоянные инструкции правило ниже и подставь доступный ему путь к `skills/design-hub/SKILL.md`. Можно также дать агенту эту папку как рабочую и указать на её `AGENTS.md`. Для облачного агента файлы Hub должны быть доступны в его среде.

> При проектировании, реализации или визуальном ревью сайта, UI, презентации или другого дизайнерского материала сначала прочитай `<путь к Design Hub>/skills/design-hub/SKILL.md` и следуй маршруту для этой задачи.

Сохраняй здесь правила и инструменты, которые пригодятся в нескольких проектах. Подходы, относящиеся к одному бренду или продукту, храни в его проекте. Зафиксированный Cook обновляй отдельной проверкой исходников и скриптов.
