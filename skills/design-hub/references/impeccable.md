# Impeccable в Design Hub

[Локальный скилл](../../../vendor/impeccable/SKILL.md) содержит сценарии команд, руководства по вебу и нативным интерфейсам, правила проектирования и вспомогательные скрипты. Полный открытый комплект версии 4.10.0 закреплён на коммите `b49177d32788f2dc585c42831d845dacf1ebed2c` и сохранён на D:. [Полный комплект на D:](D:/DrawingAI_runs/design-hub-impeccable-2026-11-22/source) · [Исходный коммит](https://github.com/pbakaus/impeccable/tree/b49177d32788f2dc585c42831d845dacf1ebed2c) · [Лицензия](../../../vendor/impeccable/LICENSE) · [Уведомления](../../../vendor/impeccable/NOTICE.md).

В полном комплекте есть исходники движка и CLI, расширение браузера, плагины, сборки для нескольких агентов, хуки, примеры, тесты и техническая документация. Задействуй нужные части по задаче. Установку хуков и расширений выполняй, когда пользователь просит их подключить.

Для работы офлайн доступны [правила детектора в JSON](D:/DrawingAI_runs/design-hub-impeccable-2026-11-22/source/crates/live/assets/antipatterns.json), [демо лендинга](D:/DrawingAI_runs/design-hub-impeccable-2026-11-22/source/demos/landing-demo/index.html) и [технические руководства](D:/DrawingAI_runs/design-hub-impeccable-2026-11-22/source/docs).

## Запуск

Оставь рабочим каталогом целевой проект. В Windows используй [команду Design Hub](../../../tools/Invoke-Impeccable.ps1) по её абсолютному пути. Она подхватывает движок с D: и локальный скилл Hub. Где `.ps1` запрещены, вызывай [запуск через Python](../../../tools/impeccable.py) с теми же аргументами. Начни с `context --target <файл-или-маршрут>` для веба или UI либо с `detect --json <файл-или-URL>` для отдельной проверки. Смотри [примеры детектора](tools.md#impeccable).

Для агента на другой машине открой локальный `SKILL.md` и используй штатный лаунчер из `vendor/impeccable/scripts` в соответствии с документацией автора. [Установка Impeccable](https://impeccable.style/tutorials/getting-started/).

| Задача | Что открыть |
|---|---|
| Новый UI или редизайн | Сначала уточни [режим концептов](image-concepts.md), если визуальное направление открыто. Для реализации выбранной картинки открой [руководство по реализации макета](../../../vendor/impeccable/reference/new-work-comp.md). Для прямой работы используй [руководство по новому дизайну](../../../vendor/impeccable/reference/new-work.md). |
| Ревью и проверка | `critique` для визуальной иерархии и сценария, `audit` для доступности и адаптивности, `detect` для автоматических проверок. |
| Улучшение существующего UI | Выбери playbook по задаче. Например, `layout`, `typeset`, `clarify`, `polish`, `adapt` или `harden`. |
| Работа с дизайн-системой | `init` для контекста продукта, `document` для существующей визуальной системы, `extract` для повторного использования компонентов и токенов. |
| Варианты существующего веб-интерфейса | Когда пользователь просит работу в браузере и есть локальный сервер, смотри `live` и `generate`. Для применения правок Windows-обёртка оставляет управление в активном чате. |
